# Kuro & Cream

*My first independently developed multi-page website, combining my love for cats and coffee.*

## Project Overview

Kuro & Cream is a personal cat café website created to strengthen my foundational HTML and CSS skills. I wanted to challenge myself to build a cohesive, multi-page website where visitors could explore a fictional café while navigating between different sections.

## Technologies Used

- **HTML5** — Semantic structure and page organization
- **CSS3** — Website styling, layouts, and visual design

## Key Features

- **Multi-Page Navigation:** Connects separate webpages through a shared navigation system.
- **Cat and Café Menus:** Dedicated pages showcasing the café's cats and offerings.
- **Consistent Styling:** Maintains a cohesive visual identity across the website.
- **Semantic HTML:** Organizes content using meaningful HTML elements.

## Development Process

Inspired by my love for cats and coffee, I created a café concept that would allow me to practice building a website independently.

I developed the site using HTML and CSS, focusing on consistent layouts, navigation, and styling across multiple pages. I also practiced semantic HTML and CSS validation to improve the structure and reliability of my code.

## Challenges & Outcomes

As my first independent multi-page website, Kuro & Cream challenged me to move beyond individual webpages and build a connected experience.

I learned how to organize multiple HTML files, maintain consistent styling, and create navigation between pages. The finished project became a foundation for the more interactive websites I developed later.
